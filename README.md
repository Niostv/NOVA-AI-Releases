# NOVA AI — HTML-версия

Самодостаточный интерфейс AI-ассистента на HTML, CSS и JavaScript без сборщика.

## Запуск

1. Дважды щёлкните `start.bat`.
2. Откройте `http://localhost:8080`.
3. По умолчанию NOVA использует Puter Cloud: скачивать модель или вводить API-ключ не нужно. При первом запросе Puter может попросить разрешение или вход.
4. Ollama остаётся дополнительным локальным режимом и выбирается в настройках.

История и настройки сохраняются только в `localStorage` браузера. Локальный `server.py` передаёт потоковые ответы от Ollama и устраняет браузерную ошибку CORS/`Failed to fetch`. Для другого адреса Ollama задайте переменную окружения `OLLAMA_URL`. Интернет-поиск и генерация изображений требуют отдельного безопасного backend-провайдера и не имитируются.
